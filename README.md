TensorFlow Basics - Linear Regression

Author: SELVASH

Project Description

This project demonstrates a simple linear regression model using TensorFlow and Python.

Objective

To predict an output based on an input value using machine learning.

Technologies Used

- Python
- TensorFlow
- NumPy

Dataset

Input values: 1, 2, 3, 4, 5

Output values: 2, 4, 6, 8, 10

Example Prediction

Input: 6

Expected output: Approximately 12

How to Run

1. Install Python.
2. Install the required libraries:
   "pip install tensorflow numpy"
3. Run the program:
   "python linear_regression.py"
